# Opticalav Online Mağaza

Av, optik ve taktik ekipman mağazası. Netlify üzerinde çalışır (statik sayfalar + Netlify Functions + Netlify Blobs).

- Mağaza: `/`
- Yönetim paneli: `/admin.html` (ürün, fotoğraf, sipariş, mağaza bilgileri, iyzico ayarları)
- Kartla ödeme: iyzico Checkout Form (anahtarlar yönetim panelinden girilir)
- Havale/EFT: IBAN bilgisi yönetim panelinden girilir
